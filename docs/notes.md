# System Simulator

A terminal-based demo project that generates fictional telemetry for local systems.

## Purpose
This project is a harmless simulation built for learning, experimentation, and presentation in a terminal environment.

## Project goals
- generate synthetic system data
- emulate a dashboard style interface
- keep everything local and offline
- provide a clean, simple repository for a first public project

## Important note
This repo does not connect to real systems or scan devices. It is purely a fictional simulation.
